How to upscale an image online for free

Start with the largest original file you have. A saved photo is usually a better source than a screenshot or an image repeatedly compressed by a messaging app.

  1. Choose an image. Open the AI image upscaler and select a JPG, PNG or WebP file. Each source can be up to 20 MB, 12 megapixels and 12,000 pixels on either side.
  2. Select a model and size. Start with Photo for a photograph, Illustration for drawn artwork. Choose 2× or 4×, or switch to Print format.
  3. Compare a small area. Use “Compare models on a crop” to preview a central area. Inspect the original and both model previews before committing to the full image.
  4. Upscale and inspect. Run the selected model and compare the result at 100%. Check faces, fine textures, lettering and transparent edges.
  5. Download the result. Choose PNG for transparency or JPEG for a smaller photographic file. Use the DPI setting if you are preparing a print.

Which AI model should I use for photos?

Photo is the default photo upscaling model. It uses Real-ESRGAN general x4v3 with adjustable noise reduction. Begin with a moderate setting and compare the crop: stronger noise reduction may also smooth natural texture.

No model is best for every image. A model trained for illustrations may simplify photographic texture. The Photo model is more demanding and can be slow on CPU. Use the crop comparison to choose based on the actual image.

Edge smoothing is a separate finishing control. Its default is 0%. Raise it only when jagged edges need softening; high values can soften small details too.

Increase image resolution: what do 2× and 4× mean?

The scale factor multiplies both width and height. A 4× image contains 16 times as many pixels as its source. That can make a larger print or a more detailed display image possible, but it also uses more memory.

AI image enhancement estimates new detail instead of only stretching the existing pixels. It can improve some edges and textures, but it may invent or alter details. A blurred face or unreadable number cannot be reconstructed with guaranteed accuracy.

For a 4K image: 960 × 540 px at 4× produces 3840 × 2160 px. “4×” is a multiplier, not a fixed 4K preset. A source with a different size or aspect ratio will produce a different result.

Output is limited by the browser and device memory, with a maximum of 8,192 pixels per side. If the app rejects a result, use 2× or a smaller source. It is not an unlimited-resolution upscaler.

How to upscale a photo for printing: pixels vs DPI

Pixel dimensions describe the image data. DPI describes how densely those pixels are placed in a print. Image density is technically PPI (pixels per inch); the application labels the setting DPI, as many print workflows do.

Print width in cm = width in pixels ÷ DPI × 2.54

For a 400 × 300 px source enlarged 4×, the result is 1600 × 1200 px. In scale mode, changing the DPI does not change that pixel size:

Set a print format when you need a target size

Choose Output size → Print format, then A5, A4, A3, A2, a photo format or a custom size. In this mode, the physical size and DPI determine the target pixels. The app selects AI 2× or 4×, then resamples the result to fit the format while preserving the original aspect ratio. It does not crop to fill a different aspect ratio.

At 300 DPI, 40 × 30 cm needs about 4724 × 3543 px. A 1600 × 1200 px image does not become that detailed just by changing its DPI tag. If AI scaling cannot reach the requested resolution, additional resizing cannot guarantee new true detail.

What about larger canvas prints?

Follow your print provider’s specification and expected viewing distance. A textured canvas viewed across a room can tolerate a lower pixel density than a small glossy print examined closely. Ask the printer for the required pixel dimensions and order a small proof of a detailed crop before a large canvas.

Batch image upscaling, PNG transparency and JPEG export

Use Process multiple images near the bottom of the application to select up to 10 images. Each source can be up to 20 MB; the batch total is limited to 100 MB. The same settings apply to every image, and the results are available as a ZIP.

After processing, changing DPI, export format, JPEG quality or edge smoothing updates the exports without running AI again. A model or noise-reduction change requires new AI processing.

PNG is the output format for transparent backgrounds and artwork. JPEG is useful for photos when file size matters; it replaces transparent areas with white. WebP is accepted as an input, while downloads are PNG or JPEG.

A private image upscaler in your browser

Selected images are processed on your device. The website supplies the application and model downloads; it does not receive the image pixels for processing. There is no account requirement or server-side image upload step.

The app can be installed from a supported browser. Offline use requires an initial online visit and the necessary assets for the selected model to have been cached. Try that model online first. Browser storage limits, private browsing or clearing site data can remove cached files.

Processing time depends on your image, model, memory and browser acceleration. CPU processing can take minutes. Try a smaller source or compare the two models on a crop first; there is no fixed completion time.

Image upscaler FAQ

Is Photoupscale.online free, with no watermark or sign-up?

Yes. The application is free to use and does not require an account or add a watermark. File-size, pixel and batch limits still apply; processing uses your own device.

Can I upscale a photo without uploading it?

Yes. Select an image in the browser and it is processed on your device. The app downloads its code and AI models from the website, but does not send your selected image to an image-processing server.

Can it fix a blurry photo or recover lost detail?

AI can estimate sharper edges and textures in some low-resolution images. It cannot guarantee the recovery of real missing detail, correct severe motion blur or make small text accurate. Check faces, text and important details against the original.

Can I upscale an image to 4K?

There is no fixed 4K preset. In scale mode, the result is exactly 2× or 4× the original width and height, within device limits. A 960 × 540 image becomes 3840 × 2160 at 4×. A different aspect ratio produces different dimensions.

Does 300 DPI make my image larger or sharper?

In Scale 2× / 4× mode, changing DPI alone does not add pixels or sharpen the image; it changes the suggested physical print size. In Print format mode, the selected size and DPI determine target pixel dimensions, so changing DPI can change the exported resolution.

Does the app preserve transparent PNG backgrounds?

PNG export can preserve transparency. Choose PNG for logos, artwork and cut-outs. JPEG does not support transparency, so transparent areas are placed on a white background.

How do I upscale multiple images at once?

Use Process multiple images, choose up to 10 files and start the queue. The chosen settings apply to the whole batch. Download the results in a ZIP. Each input must be at most 20 MB and 12 MP, with a batch total of at most 100 MB.

Why is AI image upscaling slow in my browser?

Processing runs on your own hardware. Large images and the Photo model can take minutes, especially on CPU. Try a small crop comparison, a smaller source or 2× output. Keep the tab active and enable browser graphics acceleration when supported; speed is not guaranteed.

Can I use the image upscaler offline?

After an initial online visit, the installable app can work offline if the browser has retained the app and the assets for the selected model. Run that model online first. Installation alone does not download all models, and clearing site data removes cached assets.
